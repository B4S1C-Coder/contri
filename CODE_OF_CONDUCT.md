# Code of conduct

CONTRI exists to make open source more welcoming, and this project should be too.

## Our standards

- Be respectful and patient, especially with first-time contributors.
- Critique ideas and code, never people.
- Assume good intent, and ask before assuming.
- Welcome everyone regardless of background, experience, identity or disability.

Harassment, threats, discriminatory language, doxxing and unwanted contact are not acceptable anywhere in this project.

## Enforcement

Maintainers may edit or remove disruptive contributions and restrict participation. Report concerns privately through GitHub's reporting tools or a [private security advisory](https://github.com/alphasafal/contri/security/advisories/new) if needed; do not publish anyone's private information. Maintainers will respond fairly and explain moderation decisions when it is safe to do so.

This code of conduct is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
