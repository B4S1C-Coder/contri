# Code of conduct

Be respectful and constructive. Welcome contributors regardless of background, experience, identity, or disability. Critique ideas and code without insulting people. Harassment, threats, discriminatory language, doxxing, and unwanted contact are unacceptable.

Project maintainers may edit or remove disruptive contributions and restrict participation. Report concerns privately through GitHub's reporting tools; do not publish another person's private information in an issue. Maintainers should respond fairly and explain moderation decisions when doing so is safe.
