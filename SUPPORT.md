# Getting help

- **How do I…? / ideas:** start a thread in [Discussions](https://github.com/alphasafal/contri/discussions).
- **Something is broken:** open a [bug report](https://github.com/alphasafal/contri/issues/new?template=bug_report.yml).
- **Security problem:** report it privately — see [SECURITY.md](SECURITY.md).

Before asking, check:

- **A badge or the widget doesn't appear** — reload the GitHub tab after installing or updating CONTRI. GitHub sometimes changes its page layout; tell us in an issue and include the URL.
- **“GitHub request limit reached”** — anonymous use has 60 requests per hour. Sign in from CONTRI's settings for 5,000.
- **On-device AI buttons are missing** — they need a Chrome version and device that support built-in AI (Gemini Nano). The contribution brief works everywhere.

Never share a GitHub token in an issue, discussion or screenshot.
