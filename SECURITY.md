# Security

Do not post tokens, account details or sensitive logs in public issues. Revoke any exposed GitHub token immediately.

For a security concern, use GitHub's private vulnerability reporting on this repository when enabled. If unavailable, open a minimal issue requesting a private contact without including exploit details or secrets.

Security boundaries: public repositories only; optional GitHub token held by the service worker and trusted extension settings; no AI API calls; strict GitHub message validation; no remote executable code. Local extension storage is not an encrypted vault.
